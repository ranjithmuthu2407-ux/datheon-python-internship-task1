# Datheon Python Internship

## Task 1: Hangman Word Guessing Game

A simple word-guessing game developed using Python.

### Features
- Random word selection
- Letter guessing
- Maximum of 6 incorrect attempts
- Input validation
- Win or lose result
- Replay option

### Technologies Used
- Python 3

### How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the terminal in the project folder.
4. Run the following command:

python hangman.py
